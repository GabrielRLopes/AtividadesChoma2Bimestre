# Atividade Choma 2Bimestre

Atividades do segundo bimestre de Teste de Software.

| Semana | Atividade | Situação |
| --- | --- | --- |
| [10](SEMANA10/) | Implementação com TDD em quatro projetos Java | 50 testes aprovados e 100% de cobertura JaCoCo por módulo. |
| [11](SEMANA11/) | Testes de integração em Spring Boot com H2 e MockMvc | 5 testes aprovados, incluindo o desafio de atualização de preço. |
| [14](SEMANA14/) | Teste de usuário no fluxo de compra do Mercado Livre | Execução técnica e ficha preenchidas. O login bloqueou a adição ao carrinho. |

## Como executar

Com JDK 17 e Maven, execute a partir da raiz.

```shell
mvn -f SEMANA10/pom.xml clean verify
mvn -f SEMANA11/pom.xml clean test
```

Os resultados e o roteiro de observação estão nos READMEs de cada atividade. [Material da disciplina](https://github.com/JoaoChoma/teste_software_2026)
