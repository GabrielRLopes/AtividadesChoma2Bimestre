# Bubble Sort

O método `ordenar()` ordena o vetor recebido em ordem crescente por trocas adjacentes. Uma passagem sem trocas encerra a ordenação.

Os testes fornecidos cobrem vetores desordenados, já ordenados e com repetições. A suíte inclui ainda vetores vazios, unitários e com valores inteiros extremos.

Execute `mvn clean verify` nesta pasta. Veja o enunciado em [REQUISITOS.md](REQUISITOS.md).
